root `README.md` renders correctly.

| File | What to capture |
|---|---|

| `settings-connected.png` | Settings after a successful connection test, with the gateway list visible. |
| `add-application.png` | Add Application modal with the running-process list visible. |
| `app-list.png` | Main app list showing apps in Synchronized and LocalOnly states. |
| `confirm-apply.png` | ConfirmApplyDialog open, listing pending QoS/firewall changes. |
| `apply-failures.png` | ApplyFailuresDialog open, showing the failure list and action buttons. |
| `verify-route.gif` | 30-second GIF of the full flow: add app → sync → apply → verify ✓. |

Keep PNGs under ~400 KB and GIFs under ~2 MB when possible.
